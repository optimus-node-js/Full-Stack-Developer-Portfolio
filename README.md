## ✨ Highlights

- **Multi-page architecture** with Framer Motion page transitions and dedicated project detail pages
- **Interactive terminal** — explore my profile with Linux-style commands
- **AI chatbot** (serverless `api/chat.ts`) that answers questions about my experience
- **Creative experience layout** with an experience switcher instead of a plain timeline
- **Book a call** — Cal.com embed; contact form via EmailJS; newsletter modal
- **Light & dark modes** with animated theme toggles, particle/code-rain backgrounds
- **Mobile-first polish** — iPhone-style glassmorphism bottom nav
- **SEO** — OG share cards, sitemap, robots, web manifest; analytics

## 📂 Structure

```
frontend/   React + Vite app (components, pages, data, hooks)
api/        Vercel serverless functions (AI chat)
backend/    FastAPI service (optional)
```

## 🚀 Run locally

```bash
git clone https://github.com/optimus-node-js/Full-Stack-Developer-Portfolio.git
cd Full-Stack-Developer-Portfolio/frontend
```

```bash
npm install
npm run dev
```

AI chat requires an LLM API key in the Vercel project environment (never commit it).
